Ввод только по ID

Вставь список ID ассетов — Mimi определит их тип и владельца.

Сбор списка из Studio

Плагин собирает ID анимаций и звуков прямо из твоего проекта.

четыре шагаКак начать

  1. 1

    Скачай и распакуй архив

    Возьми его на странице релиза.

  2. 2

    Приложение умеет сохранять файл плагина.

Данные остаются у тебя

  • Профиль, Cookie и прочая конфиденциальная информация хранятся локально на твоём компьютере, в APPDATA.
  • В телеметрию уходят только публичные ID Roblox-аккаунтов.
